CRAZY SOUND LAB - SOUNDS FOLDER

Put real audio files in category subfolders.
Examples:
  sounds/animals/dog-bark.wav
  sounds/people/baby-cry.mp3
  sounds/foley/door-slam.wav

Use admin.html to add the file to the public catalog. Admin cannot physically move or delete files on your computer (the browser blocks that for security), so copy/delete the actual audio file in Windows Explorer.
